# Business Management Platform

A portfolio-ready business operations platform for managing customers, service requests, work orders, assignments, priorities, status tracking, and operational KPIs.

## Project Goal

This project demonstrates end-to-end JavaScript development with Node.js, Express, REST APIs, authentication, PostgreSQL-compatible persistence, validation, testing, Docker, CI, and a responsive business dashboard.

## Core Modules

- Authentication
- Users and roles
- Customers
- Service requests
- Work orders
- Assignments
- Status and priority tracking
- Dashboard KPIs
- Search and filtering
- REST API

## Tech Stack

- JavaScript
- Node.js
- Express
- PostgreSQL / pg
- Zod
- JWT
- HTML/CSS/JavaScript
- Node Test Runner
- Docker
- GitHub Actions

## Status

**In development**

The first version is being built as a complete portfolio case study and will include a live public demo.
